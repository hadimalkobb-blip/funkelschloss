# Funkelschloss

Lesen lernen im Glitzerschloss – deutsche Lese-App für Kinder, mit Online-Arena (Raum-Code, ohne Konto).

- Spielen: https://hadimalkobb-blip.github.io/funkelschloss/
- Online-Räume und Familien-Code: Supabase Realtime + RPC (öffentlicher anon-Schlüssel, keine Geheimnisse im Code).
- `.github/workflows/keepalive.yml` hält den kostenlosen Server täglich wach.
